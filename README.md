# LotusProject

## Technical Overview

- **Framework:** .NET Core
- **Database Management:** Entity Framework Core
- **Authentication & Security:** JWT (JSON Web Tokens)
- **Architecture:** RESTful Web APIs

---

## Backend Features & Functionalities

- **Authentication & Authorization:** Secure user registration, login, and JWT-based session management.
- **Data Models & Endpoints:** Database design and API endpoints supporting user management, community forum posts, expert consultation scheduling, second-hand product marketplace listings, and health content delivery.
- **Database Operations:** Relational database structuring and ORM mappings via Entity Framework Core.
